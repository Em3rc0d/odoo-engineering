# ADR-0003 — Conocimiento antes de implementación

**Fecha:** 2026-10-13 — **Status: ACCEPTED**.

**Contexto:** el inventario Odoo tiene ejercicios, snippets y flujos, pero carece de pruebas Odoo verificadas en este trabajo.

**Decisión:** aceptar documentación MK0/MK1, validador JSON/Markdown y referencias. Bloquear addon/piloto productivo hasta tener caso real y gates G3/G5.

**Consecuencias:** la palabra `solidez` se limita a trazabilidad documental; no se confunde con solidez operacional.
