# ADR-0005 — Complete coverage without false completeness

Status: ACCEPTED, 2026-10-13.

The `COPY → ADAPT → IMPROVE` strategy means including candidate functionality for each meaningful Odoo theme while documenting what is merely indexed, rewritten, held, or untested. Avoid importing conflicting `board.format` definitions and web client overrides. License is checked **at addon/file level**, not presumed from a public repository. MK3 contains no testing claims. The seven course addons remain an indexed upstream curriculum, not seven functioning cloned addons.
