# ADR-0002 — No importar código de terceros

**Fecha:** 2026-10-13 — **Status: SUPERSEDED by ADR-0004 (licensed modules may be adapted with attribution)**.

**Contexto:** cinco repositorios observados sin licencia raíz identificada y con inconsistencias técnicas.

**Decisión:** conservar links por SHA, hallazgos y patrones redactados originalmente. No copiar fuentes, pruebas, imágenes ni archivos de los repositorios originales. Importación futura requiere licencia y análisis de dependencia.

**Consecuencias:** no se pueden ejecutar los addons desde este archivo documental, pero se evita representar código ajeno como certificado.
