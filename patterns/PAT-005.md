# PAT-005 — Chatter y cron explícitos

- **Categoría:** `BACKEND`
- **Estado:** `DOCUMENTED_NOT_RUNTIME_VALIDATED`
- **Evidencia base:** [FND-005](../findings/FND-005.md).

## Problema y regla

Cron debe tener logging definido, dependencias correctas, modelo con mixins requeridos y política idempotente de notificaciones.

## Validación exigida

Ejecución manual del cron, vencimientos límite, duplicados, usuario sin email, transacciones fallidas.

## Limitaciones / no aplicar ciegamente

El resultado depende de configuración mail y permisos; nunca asegurar envío por solo invocar message_post.

## Gate

Revisión oficial Odoo 19 + caso de prueba en base desechable + logs conservados. Sin ello no subir estado a `RUNTIME_VALIDATED`.
