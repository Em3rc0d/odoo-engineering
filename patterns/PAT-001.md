# PAT-001 — Agrupación ORM compatible con Odoo 19

- **Categoría:** `ORM`
- **Estado:** `DOCUMENTED_NOT_RUNTIME_VALIDATED`
- **Evidencia base:** [FND-002](../findings/FND-002.md), [FND-011](../findings/FND-011.md).

## Problema y regla

Usar la semántica documentada de _read_group: filas como tuplas de valores agrupados + agregados en orden, con grouped values relacionales como recordsets. Evitar tratar resultados como diccionarios por defecto.

## Validación exigida

Prueba multirregistro con 0, 1, 2 elementos; resultados para grupos inexistentes; validar métodos y agregados contra ORM 19.

## Limitaciones / no aplicar ciegamente

No asumir compatibilidad 16/17/18 ni usar snippets ajenos sin verificarlos.

## Gate

Revisión oficial Odoo 19 + caso de prueba en base desechable + logs conservados. Sin ello no subir estado a `RUNTIME_VALIDATED`.
