# Clean-room OWL reimplementation

Observed idea: https://github.com/JoseCarlosLuque/proyecto_OWL/tree/5f332442777fc74a83763e29f65a2093b82484f1

Original standalone OWL+Vite dashboard is **not licensed for copying**, so this is newly written Odoo web-client code. Improvements on design intent: native Odoo client action and ORM service; model ACL respected; server gate for salesperson access; products derived from sale order lines rather than ID parity; currency totals separated; a 500-order sample explicitly labelled, not presented as all-time revenue. **UNTESTED** Odoo 19 and not suitable for accounting / executive KPI decisions.
